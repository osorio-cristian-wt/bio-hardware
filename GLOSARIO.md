# Glosario — Neuronas humanas como hardware de IA

| Sigla / término | Significado |
|---|---|
| **OI** | Organoid Intelligence — agenda de investigación (Johns Hopkins) para usar organoides cerebrales como sustrato de cómputo biológico, complementario a la IA de silicio. |
| **SBI** | Synthetic Biological Intelligence — término usado por Cortical Labs para el sistema híbrido neurona-silicio (DishBrain, CL1). |
| **Wetware computing** | Término de FinalSpark para describir cómputo realizado sobre tejido biológico vivo (neuronas), por analogía con "software"/"hardware". |
| **Organoide (cerebral)** | Cultivo 3D de células derivadas de células madre que se autoorganiza imitando estructura y función de tejido cerebral real, a escala miniatura (sub-milimétrica). |
| **iPSC** | Induced Pluripotent Stem Cell — célula madre pluripotente inducida; se obtiene reprogramando células adultas (ej. de piel o sangre) para que puedan diferenciarse en neuronas u otros tipos celulares. |
| **MEA** | Multi-Electrode Array — array de microelectrodos usado para estimular y registrar la actividad eléctrica de las neuronas en cultivo; es la interfaz física entre el tejido biológico y la electrónica. |
| **Reservoir computing** | Paradigma de cómputo donde un sistema dinámico complejo (el "reservorio" — puede ser el organoide) transforma señales de entrada de forma no lineal, y solo se entrena una capa de lectura externa simple (regresión), sin ajustar las conexiones internas del reservorio. |
| **Principio de energía libre (FEP)** | Marco teórico de Karl Friston: los sistemas biológicos actúan para minimizar la "sorpresa" o el error de predicción respecto a su modelo interno del entorno. Usado para explicar el aprendizaje de DishBrain — y, según sus críticos, para argumentar que el sistema podría experimentar displacer al fallar. |
| **Sentience / sentiencia** | Capacidad de tener experiencias subjetivas (placer, dolor). Término deliberadamente usado en el título del paper original de DishBrain, y fuente central de la controversia terminológica del campo. |
| **Estatus moral** | Categoría bioética: si una entidad merece consideración moral directa (no solo instrumental) — determina qué límites aplican a la investigación sobre ella. |
| **ELSI** | Ethical, Legal, and Social Issues — marco estándar para analizar tecnologías biomédicas emergentes desde tres dimensiones simultáneas. |
| **IRB** | Institutional Review Board — comité institucional que revisa la ética de investigación con sujetos humanos (protección del donante, consentimiento). |
| **IACUC** | Institutional Animal Care and Use Committee — comité institucional que supervisa el bienestar animal en investigación. |
| **ESCRO** | Embryonic Stem Cell Research Oversight — comité de revisión adicional específico para investigación con material derivado de células madre embrionarias. |
| **Quimera (humano-animal)** | Organismo que contiene células de dos especies distintas — en este contexto, típicamente células neuronales humanas trasplantadas a un cerebro animal no-humano. |
| **MPS** | Microphysiological system — sistema microfisiológico; término técnico paraguas que incluye organoides y otros modelos in vitro que imitan función de órganos. |
| **CL1** | Producto comercial de Cortical Labs (lanzado 2025): computadora biológica con ~800.000 neuronas humanas sobre un chip de 59 electrodos, USD 35.000. |
| **Neuroplatform** | Plataforma comercial/académica de FinalSpark que da acceso remoto pago a organoides cerebrales vivos vía la nube ("wetware-as-a-service"). |
| **Baltimore Declaration** | Declaración de visión a 10 años producida en el primer workshop de OI (Johns Hopkins, feb. 2022) para constituir OI como disciplina científica. |
| **Conectoma** | Mapa completo de las neuronas de un cerebro y todas sus conexiones sinápticas — el "diagrama de cableado" de un sistema nervioso. Logrado por primera vez para un cerebro adulto completo en *Drosophila* (FlyWire, 2024). |
| **Whole Brain Emulation (emulación de cerebro completo)** | La idea de recrear digitalmente el funcionamiento de un cerebro a partir de su conectoma, corriéndolo como simulación en una computadora. Demostrado a escala de mosca (2024); a escala humana es, hoy, una aspiración declarada, no un proyecto en curso. |
| **"Pacear la frontera" (pacing the frontier)** | Propuesta de Dario Amodei (Anthropic, 2026): no detener el desarrollo de IA, pero sí ralentizar deliberadamente el ritmo de mejora de capacidades para dar tiempo a alinearlas y verificarlas con seguridad. |
| **Reinforcement Learning (RL) / Aprendizaje por refuerzo** | Paradigma de entrenamiento de IA donde un agente aprende por prueba y error a partir de una señal de recompensa (positiva o negativa), en vez de ejemplos etiquetados. |
| **Condicionamiento operante** | Teoría de B.F. Skinner: la conducta (humana o animal) se moldea por sus consecuencias — refuerzo (aumenta la conducta) o castigo (la disminuye). Base de la analogía "el bebé y el caramelo". |
| **"Reward is Enough"** | Hipótesis de posición de DeepMind (Silver, Singh, Precup, Sutton, 2021): maximizar una señal de recompensa alcanzaría, por sí sola, para producir todas las capacidades asociadas a la inteligencia natural y artificial. Contestada por la réplica académica "Scalar reward is not enough" (2022). |
| **Hard problem of consciousness / Problema difícil de la consciencia** | Formulado por David Chalmers: incluso explicando toda la función y estructura de un sistema, se puede seguir preguntando por qué eso genera experiencia subjetiva. Distingue los "problemas fáciles" (qué hace un sistema) del "problema difícil" (por qué se siente desde adentro). |
| **Fisicalismo / funcionalismo** | Postura filosófica: la consciencia se reduce por completo a procesos físicos y funcionales — replicable en cualquier sustrato que cumpla la función correcta. |
| **Dualismo** | Postura filosófica: la consciencia es un fenómeno de otra naturaleza, no reducible a lo físico. Incluye nociones religiosas/filosóficas como el alma. |
| **Panpsiquismo** | Postura filosófica: la experiencia es una propiedad fundamental de la materia misma, presente en distinto grado en todo, no solo en cerebros complejos. |
